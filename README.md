# Liver Cirrhosis Prediction

A machine learning web application that predicts survival outcomes for liver cirrhosis patients and provides evidence-based drug recommendations based on disease stage.

## Project Overview

**Prediction target:** Patient survival status — Alive (C), Liver Transplant (CL), or Deceased (D)  
**Key approach:** Uses disease Stage alongside lab values as predictive features  
**Drug recommendation:** Evidence-based treatment protocols mapped from entered Stage  
**Best model:** Random Forest — Val Macro AUC: 0.832

## Features

- **3 user roles:** Admin · Lab Technician · Medic
- **Lab tech** enters patient lab values and submits for prediction
- **Medic** views survival prediction, confidence score, probability breakdown, and drug recommendation
- **Admin** manages users, views all predictions, exports CSV
- All predictions stored in SQLite database

## ML Pipeline

| Notebook | What it does | Saves |
|----------|-------------|-------|
| 01 — Load & Explore | Load CSVs, distributions, visualisations | — |
| 02 — Preprocess & Encode | Drop leakage cols, outlier capping, encoding, feature selection | `processed/` |
| 03 — Train & Evaluate | Split, scale, SMOTE-ENN, GridSearchCV, evaluate, save model | `models/` |

**Selected features (top 7 by correlation with Status):**  
Bilirubin · Prothrombin · Copper · Hepatomegaly · Stage · SGOT · Spiders

**Models compared:** Logistic Regression · Random Forest · XGBoost  
**Selected:** Random Forest (Val Macro AUC: 0.832)

## Setup & Running Locally

### 1. Clone the repository
```bash
git clone https://github.com/your-username/liver-cirrhosis-prediction.git
cd liver-cirrhosis-prediction
```

### 2. Create virtual environment
```bash
python -m venv venv
source venv/bin/activate        # Mac/Linux
venv\Scripts\activate           # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the notebooks (in order)
Open each notebook in Jupyter or Google Colab and run all cells:
1. `notebooks/notebook_01_load_explore.ipynb`
2. `notebooks/notebook_02_preprocess_encode.ipynb`
3. `notebooks/notebook_03_train_evaluate.ipynb`

This generates the `models/` folder with all required `.pkl` files.

### 5. Run the Flask app
```bash
python run.py
```

Open [http://localhost:5000](http://localhost:5000)

## Drug Recommendation Protocol

| Stage | Primary Treatment |
|-------|------------------|
| Stage 1 (Early) | Ursodeoxycholic acid (UDCA) 13–15 mg/kg/day |
| Stage 2 (Moderate) | UDCA + Spironolactone + Beta-blockers |
| Stage 3 (Advanced) | Spironolactone + Furosemide + Propranolol |
| Stage 4 (End-stage) | Transplant evaluation + Rifaximin |
